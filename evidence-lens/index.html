Verify the claim before amplifying the conclusion.

An evidence-first fact-checking desk and browser extension, built alongside the Agent Fr3k local desktop agent interface. It separates factual verdicts from rhetoric signals and preserves the source evidence behind each assessment.

Boundaries and open gates

What we will not pretend is finished.

  • Rhetoric analysis is not a factual verdict.
  • Local storage and provider API calls have distinct privacy boundaries.
