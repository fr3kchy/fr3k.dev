# fr3k.dev

Personal site for **fr3k** (Michael Insch) — autonomous AI systems architect, North Queensland, Australia.
Cyberpunk **neon-glassmorphism** styling (after simarweb.com). Built as a zero-build static site.

## Stack
- Plain HTML + CSS + vanilla JS (no framework, no build step)
- Orbitron / Rajdhani fonts (Google Fonts)
- Deploys to Vercel as a static site

## Local preview
```bash
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy (Vercel)
```bash
vercel          # first deploy / link
vercel --prod   # promote to production
```
Domain `fr3k.dev` is configured in the Vercel dashboard (DNS via the registrar).
